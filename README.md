# Minimal Resume Template

Small, modern, and minimal resume site template using plain HTML, CSS, and inline JavaScript.

Preview

Open `index.html` in a browser (double-click or use a simple static server).

Notes

- Edit content directly in `index.html`.
- CSS is in `styles.css`.
- JavaScript is inline in `index.html` (theme toggle + current year).
